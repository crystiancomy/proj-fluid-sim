# 2D Particle Fluid Simulation (Taichi)

A real-time GPU-based particle simulation built with Taichi in Python.
Includes gravity, particle collisions, and boundary constraints.

## Features

- Pairwise spring-based collision model
- Real-time visualization
- Vulkan backend
